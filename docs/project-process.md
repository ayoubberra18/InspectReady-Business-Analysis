# Project Process

This project followed a structured path from problem discovery to a final business pitch.

1. **Choose a problem area** — contractor inspection delays, failures, rework, and uncertainty.
2. **Scan macro changes** — digitization, AI/computer vision, drones, remote workflows, inspection bottlenecks.
3. **Identify recurring complaints** — failed inspections, rework, scheduling uncertainty, code interpretation.
4. **Map existing solutions** — municipal systems, construction software, inspection tools, human workarounds.
5. **Identify white space** — contractor-focused pre-inspection readiness.
6. **Draft problem hypotheses** — testable versions of the user/problem/root-cause relationship.
7. **Write a sharp problem statement** — user + context + problem + consequence.
8. **Define the primary user** — small and mid-sized general contractors.
9. **Identify riskiest assumptions** — pain, trust, behavior change, willingness to pay, data access.
10. **Validate using online behavior** — qualitative research in contractor discussions and forums.
11. **Analyze competitor complaints** — identify workflow and reliability gaps in current alternatives.
12. **Estimate TAM / SAM / SOM** — bottom-up modeled market sizing.
13. **Define Why Now** — AI vision, digital workflows, mobile capture, drones, and remote review.
14. **Run Crazy 8's** — generate multiple solution mechanisms before choosing one.
15. **Select the solution direction** — AI-assisted readiness + phone/drone capture + human escalation.
16. **Create a solution sketch** — three-screen storyboard.
17. **Build the first prototype** — jobsite-focused mobile workflow.
18. **Prepare a short product demo** — user action → product response → outcome.
19. **Build market-validation evidence** — directional findings, user quote, market model.
20. **Map competitors** — compare categories and identify positioning opportunities.
21. **Test business-model options** — subscription, per-use, marketplace, drone add-on.
22. **Create the final pitch** — problem, solution, product, validation, competition, business model, next steps.
23. **Define real-world MVP tests** — contractor interviews and pilot testing.
