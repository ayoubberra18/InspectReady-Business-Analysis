# Problem Validation

## Primary user

Small and mid-sized general contractors managing projects that require municipal inspections.

## User goal

Pass inspections with fewer surprises and keep projects moving on schedule.

## Sharp problem statement

General contractors struggle to know whether completed work will pass a municipal building inspection before scheduling it, because code compliance can be difficult to verify in advance. The consequence can be failed inspections, rework, repeat visits, additional labor cost, and project delays.

## Directional qualitative findings

The project analyzed contractor/forum discussions and grouped recurring complaints into three themes:

| Pain point | Directional frequency |
|---|---:|
| Failed inspections / rework / repeat visits | 62% |
| Timeline uncertainty | 54% |
| Code interpretation / inspector expectations | 46% |

These percentages describe the qualitative sample used in the project. They should not be interpreted as population-level statistics.

## Riskiest assumptions

- The problem is costly enough that contractors actively seek a solution.
- Contractors will change their current inspection-preparation behavior.
- Contractors will trust AI-assisted findings enough to act on them.
- Contractors will pay for risk reduction.
- Jurisdiction-specific code information can be integrated reliably.
