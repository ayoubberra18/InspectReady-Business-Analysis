# Prototype

The prototype demonstrates the core contractor workflow rather than a production-ready application.

![InspectReady prototype](inspectready-prototype.svg)

## Core flow

1. Select the project and inspection type.
2. Choose phone-camera or drone capture.
3. Analyze evidence against the relevant inspection context.
4. Surface potential findings, severity, and corrective actions.
5. Escalate uncertain cases to a private inspector when appropriate.
6. Generate an inspection-readiness report.

## Product principle

The product should support contractor preparation without claiming to guarantee municipal approval.
